# 외부 PR 검토 구현계획서 템플릿

이 파일은 `mydocs/pr/pr_{번호}_review_impl.md` 작성용 중앙 템플릿이다. 외부 PR 검토 중 본 저장소에서 추가 검증, 보조 패치, 재현 절차 정리가 필요할 때 사용한다. 내부 task의 `task_{milestone}_{issue}_impl.md` 형식을 외부 PR에 강제하지 않는다.
충분한 기존 계획/검토 기록을 참조·보완하며 별도 구현계획이 필요한 경우에만 작성한다. 작은 독립 LOW에는 이 파일이나 형식 Stage를 강제하지 않고 검증·결과·제약을 보고한다. 명시 요청된 산출물은 작성한다.

## 사용 위치

- 실제 파일: `mydocs/pr/pr_{번호}_review_impl.md`
- 작성 시점: Scope 내 추가 검증이나 보조 작업에 별도 계획이 필요할 때. 일반 검토/계획 승인 대기를 요구하지 않는다.
- 작성 언어: 이 저장소에 선택된 Hyper-Waterfall locale을 따른다.

## Scope·Checkpoint·필요한 승인

- Scope: {목표·대상·수용 기준·제약}
- LOW/명확한 MEDIUM의 범위 내 계획·검증·보조 수정·리뷰·기록·Stage 전환은 응답 대기 없이 수행한다. Stage 수에 고정 최소/최대 수를 두지 않는다.
- Checkpoint: {진행 상태·검증·Evidence·제약·인계. 비차단 기록이며 Human Approval과 구분한다.}
- HIGH 결정/행동·큰 Scope 확장: {결정·범위·근거와 기존 명시 승인 기록 또는 승인 필요. 없으면 없음}
- 미승인/거절 행동과 의존 작업만 보류하고 독립 안전 작업은 계속한다. 동일 결정 승인과 충분한 기존 계획은 재사용한다.
- 기록 작성은 local commit·외부 게시·merge·close·Git 작업 권한을 확대하지 않는다. 기존 finite safety cap·영속 counter·동일 실패 resume 누적·blocked 규칙과 실제 차단/정상 종료 HALT를 유지한다.
