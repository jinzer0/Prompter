# macOS BrowserWindow titlebar hiddenInset 적용 수행계획서

GitHub Issue: [#14](https://github.com/jinzer0/Prompter/issues/14)
마일스톤: M012

## 목적

`electron/window-options.ts`의 BrowserWindow 생성 옵션에 macOS `titleBarStyle: "hiddenInset"`를 적용해 Prompter의 compact dark native shell과 macOS traffic light 영역이 더 자연스럽게 이어지도록 한다. 기존 보안 중심 `webPreferences`는 변경하지 않고 창 생성 동작을 검증한다.

## 배경

Prompter는 macOS-focused Electron 앱이며 DESIGN.md는 native command-center 느낌의 compact dark shell을 요구한다. 현재 `createWindowOptions()`는 기본 titlebar를 사용하므로 앱 shell과 OS chrome이 분리되어 보일 수 있다. 이 task는 디자인 리팩토링 후보 중 가장 독립적인 Electron window 옵션 개선이다.

## 범위

### 포함

- `electron/window-options.ts`의 BrowserWindow 옵션 수정
- 기존 `webPreferences`와 preload/security 옵션 유지 확인
- macOS 창 titlebar/traffic light 수동 확인 또는 smoke 검증 기록

### 제외

- renderer layout 대규모 변경
- 커스텀 draggable titlebar 구현
- macOS 외 플랫폼별 별도 chrome 정책 추가
- 디자인 토큰 또는 색상 팔레트 변경

## 설계 방향

- `titleBarStyle: "hiddenInset"`만 우선 적용하고, 기존 창 크기와 renderer grid 정책은 보존한다.
- Electron BrowserWindow 옵션 타입에 맞춰 명시적인 literal 값을 사용한다.
- 시각 확인은 구현 단계에서 앱 실행 또는 smoke로 수행하고, 문제가 있으면 renderer padding 보정은 별도 승인 대상으로 분리한다.

## 리스크

- **타이틀바 inset와 콘텐츠 겹침**: hiddenInset 적용 후 traffic light가 shell 콘텐츠와 겹치면 renderer padding 보정은 별도 승인 범위로 분리한다.
- **플랫폼 차이**: macOS 중심 변경으로 유지하고, 다른 플랫폼 정책은 추가하지 않는다.
