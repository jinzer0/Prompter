# MetricGrid와 MetricCard 패턴 통합 수행계획서

GitHub Issue: [#19](https://github.com/jinzer0/Prompter/issues/19)
마일스톤: M012

## 목적

Insights, Backup, Privacy Center의 작은 metric/count 카드 패턴을 공용 MetricGrid/MetricCard primitive로 통합해 `dl/dt/dd` semantics와 compact muted card 디자인을 일관되게 유지한다.

## 배경

여러 화면에서 숫자/label card가 비슷한 구조로 구현되어 있다. 모두 DESIGN.md의 compact muted surface와 metadata typography를 따르므로 공용 primitive로 중복을 줄일 수 있다.

## 범위

### 포함

- 공용 metric primitive 추가
- `renderer/src/components/insights/insights-ui.tsx`의 metric 패턴 검토
- `renderer/src/components/backup/backup-panel-parts.tsx` CountGrid 적용 검토
- `renderer/src/components/backup/privacy-scan-counts.tsx` 적용 검토

### 제외

- Insights 데이터 계산 변경
- Backup/Privacy scan 비즈니스 로직 변경
- chart/progress bar 리디자인
- metric 색상 추가

## 설계 방향

- semantic `dl/dt/dd` 구조를 유지하는 API를 우선한다.
- 숫자 강조, label metadata, compact muted surface를 DESIGN.md 토큰으로 고정한다.
- InsightProgress 같은 progress/chart 패턴은 이번 task에서 분리한다.

## 승인 요청 사항

- Issue #19을 `local/task19`에서 시작하고 위 범위와 단계 경계로 구현계획서 작성 및 후속 구현을 진행한다.
- 수행계획서 승인 전에는 구현계획서 작성, 제품 코드 변경, 검증 목적 외 변경을 진행하지 않는다.
- 범위 제외 항목은 별도 이슈 또는 별도 승인 없이는 다루지 않는다.

승인되면 `task_m012_19_impl.md`에서 단계별 산출물, 검증 명령, 커밋 메시지를 구체화한다.
