# Prompt 선택형 카드 공용 SelectableCard 추출 수행계획서

GitHub Issue: [#17](https://github.com/jinzer0/Prompter/issues/17)
마일스톤: M012

## 목적

`PromptAssetCard`와 `PromptSearchResultCard`의 선택 가능한 card button shell을 공용 SelectableCard primitive로 추출해 Library/Search 카드 UI의 selected, hover, focus 상태를 일관되게 유지한다.

## 배경

두 컴포넌트는 native button, `aria-pressed`, card border/background, selected accent border, focus ring, title/badge/metadata/preview 구조가 거의 동일하다. 개별 구현이 계속되면 같은 prompt summary UI가 drift될 수 있다.

## 범위

### 포함

- 공용 selectable card primitive 추가
- `renderer/src/components/prompt-asset-card.tsx` 적용
- `renderer/src/components/prompt-search-result-card.tsx` 적용
- Library/Search 카드 선택 동작 검증

### 제외

- PromptAsset/SearchResult 데이터 모델 변경
- 검색 로직 변경
- 카드 레이아웃 전면 재설계
- Badge variant 변경

## 설계 방향

- SelectableCard는 button shell의 상태/표면만 책임지고 prompt-specific content는 기존 컴포넌트에 남긴다.
- `aria-pressed`, focus-visible ring, selected border를 기존과 동등하게 보존한다.
- 공용 컴포넌트는 prompt 도메인에 종속되지 않는 이름과 props로 둔다.

## 리스크

- **도메인 과결합**: 공용 shell은 prompt content를 몰라야 한다.
- **클릭/키보드 회귀**: native button semantics와 focus ring을 유지한다.

## 승인 요청 사항
