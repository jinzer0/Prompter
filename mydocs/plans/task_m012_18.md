# dialog shell과 alert dialog 패턴 공용화 수행계획서

GitHub Issue: [#18](https://github.com/jinzer0/Prompter/issues/18)
마일스톤: M012

## 목적

Privacy warning과 Backup dialog 계열의 native dialog/Card shell/focus/escape/action 패턴을 공용 DialogShell 또는 AlertDialog primitive로 정리해 접근성과 디자인 일관성을 유지한다.

## 배경

DESIGN.md는 Alert Dialog 구조와 safe cancel initial focus, Escape cancel, focus return을 명시한다. 현재 관련 구현이 여러 파일에 흩어져 있어 반복과 접근성 회귀 위험이 있다.

## 범위

### 포함

- 공용 DialogShell/AlertDialog/DialogActions 중 최소 구현 선택
- `PrivacyWarningDialog`와 backup dialog 계열 중 계획서 승인 대상 적용
- focus restore, Escape cancel, aria-labelledby/aria-describedby 검증

### 제외

- dialog 라이브러리 신규 의존성 추가
- modal UX 정책 변경
- privacy/backup 비즈니스 로직 변경
- 전체 앱 navigation 변경

## 설계 방향

- native `<dialog>`를 유지하고 Card composition만 공용화한다.
- initial focus와 restore focus 로직은 테스트 가능한 작은 함수로 유지한다.
- Backup/Privacy 도메인별 copy와 actions는 호출부가 소유한다.

- **focus 회귀**: initial safe action focus와 restore focus를 구현 전후 테스트한다.

## 승인 요청 사항
