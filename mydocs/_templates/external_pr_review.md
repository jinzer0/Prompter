# 외부 PR 검토 템플릿

이 파일은 필요한 `mydocs/pr/pr_{번호}_review.md` 작성용 중앙 템플릿이다. 외부 기여자 PR 검토의 초기 판단, 영향 범위, 검증 계획, 권고를 기록한다. 충분한 기존 검토/계획/승인 기록을 참조·보완하며 작은 독립 LOW에 별도 파일을 강제하지 않는다. 명시 요청된 산출물은 작성한다.

## 사용 위치

- 실제 파일: `mydocs/pr/pr_{번호}_review.md`
- 작성 시점: 외부 기여자 PR 메타데이터와 diff를 확인한 뒤 별도 검토 기록이 필요할 때
- 작성 언어: 이 저장소에 선택된 Hyper-Waterfall locale을 따른다.

## Scope·기존 기록·필요한 승인

- Scope: {목표·대상·수용 기준·제약}
- 기존 기록: {실제 존재하는 계획/검토/승인/Evidence 링크 또는 없음. 없는 문서의 링크를 만들지 않는다.}
- LOW/명확한 MEDIUM의 Scope 내 검토·계획·추가 검증·수정·기록·Stage 전환은 비차단으로 진행한다. Checkpoint는 상태·Evidence·인계 기록이지 승인 대기가 아니다.
- HIGH 결정/행동·큰 Scope 확장: {해당하는 결정·범위·근거와 기존 명시 승인 기록 또는 승인 필요. 없으면 없음}
- 미승인/거절 행동과 의존 작업만 보류하고 독립 안전 작업은 계속한다. 같은 결정은 기존 승인 기록을 재사용한다.
- GitHub 코멘트/리뷰 게시·merge·close와 local commit·Git 작업은 기존 권한을 별도로 따른다. 검토 권고나 기록 작성은 실행/게시 권한이 아니다.
