# M012 통합 검증 실패 후속 수정 수행계획서

GitHub Issue: [#27](https://github.com/jinzer0/Prompter/issues/27)
마일스톤: M012

## 목적

#26 통합 검증에서 발견된 실패 원인을 수정해 M012 디자인 리팩토링 병합 후 기본 검증 gate를 green 상태로 회복한다.

수정 대상은 두 가지다. 첫째, #18 dialog shell 공용화 이후 이동한 dialog helper를 Phase 19 renderer unit test가 새 위치와 이름으로 import하도록 갱신한다. 둘째, 제품 source가 아닌 `.gjc/` runtime state가 Biome lint 대상에 포함되어 실패하는 문제를 저장소 설정에서 제외한다.

## 배경

#26에서 `npm run typecheck`, `npm test`, `npm run build`는 `tests/phase19-privacy-renderer-ui.test.ts`가 더 이상 export되지 않는 `focusPrivacyDialog`, `handlePrivacyDialogKeyDown`을 import해 실패했다. 현재 helper는 `renderer/src/components/ui/dialog.tsx`의 `focusDialog`, `handleDialogKeyDown`다.

또한 `npm run lint`는 `.gjc/_session-*`, `.gjc/state/sdk/*` runtime JSON 파일 formatting을 검사해 실패했다. `.gjc/`는 agent runtime state이며 제품 source나 공식 문서가 아니므로 Biome 검사 대상에서 제외하는 것이 적절하다.

## 범위

### 포함

- `tests/phase19-privacy-renderer-ui.test.ts` import와 helper 호출 갱신
- Biome 설정에서 `.gjc/` runtime state 제외
- #26 실패 검증 재실행
- 단계 보고서와 최종 보고서 작성

### 제외

- dialog runtime 동작 재설계
- PrivacyWarningDialog copy/UI 변경
- 새 UI primitive 추가
- dependency remediation
- release/package/notarization 작업

## 설계 방향

- test import는 helper의 실제 소유 위치인 `renderer/src/components/ui/dialog`를 직접 참조한다.
- test 의미는 유지하고 이름만 현재 API에 맞춘다.
- `.gjc/` 제외는 Biome 설정의 ignore/include 계층에서 처리하며 source 파일을 포맷하지 않는다.
- 제품 코드 변경은 하지 않는다.

## 잠정 단계

- **Stage 1 — Phase 19 test import 갱신**
  - dialog helper import를 `ui/dialog`의 `focusDialog`, `handleDialogKeyDown`로 갱신한다.
  - focused typecheck/test를 실행한다.
- **Stage 2 — Biome runtime state 제외**
  - `.gjc/` runtime state를 Biome 검사 대상에서 제외한다.
  - `npm run lint`를 실행한다.
- **Stage 3 — 통합 재검증과 최종 보고**
  - `npm run typecheck`, `npm test`, `npm run build`, 가능한 경우 `npm run test:smoke`를 실행한다.
  - 최종 보고서를 작성한다.

- **긴 검증 시간**: native rebuild를 포함한 `npm test`/smoke는 오래 걸릴 수 있으나 통합 회복 확인을 위해 실행한다.
- **숨은 테스트 회귀**: focused test 통과 후 전체 `npm test`로 확인한다.
